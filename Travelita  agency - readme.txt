## Selected website theme

Travel Agency Website ( it is a business travel agency called Travelita)


## Files

- index.html                               - Home page with an introduction and three featured trips
- destinations.html                   - Nine trip cards with search and filter
- about.html                             - About section and contact form
-  style.css                                 - All the styling, including a media query for small screens
-  script.js                                  - All the JavaScript
-  images                                   - The trip pictures

## JavaScript interactions (script.js)

1. **Search and filter:** 
On the Destinations page, the search box and the category drop-down show only the trips that match. The page updates without reloading, and a message appears if no trip matches. The search box on the home page opens the Destinations page with the search already applied.

2. **Save button with counter:** 
Each trip has a Save button. Clicking it marks the trip as saved (the button changes colour and text) and updates the "Saved trips" number at the top of the page.
3. **Form validation:** 
On the About & Contact page, the form checks that the name is not empty, that the email has a valid format, and that the message has at least 10 characters. A clear error or success message is shown to the user.
